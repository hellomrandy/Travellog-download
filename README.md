# Travellog-download
Travel logger for logging your time and distance on the road
press start when you drive off and stop when you arrive.
Time and distance are saved to an Excel file.

## Download
Get the newest version under **Releases** → **TravelLog.apk**.

## Install
1. Open TravelLog.apk on your Android phone.
2. If asked, allow installing apps from this source.
3. Updates install over the old app and keep your trips.
